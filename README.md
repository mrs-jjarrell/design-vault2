# 🎨 The Design Vault: Advertising & Design Escape Room

Welcome to **The Design Vault**, an interactive escape room designed to help students explore advertising and graphic design concepts through fun, hands-on challenges!

## 🔐 Your Mission

Complete five design challenges, collect a digit from each room, and unlock the final vault!

## 🧩 The Five Design Rooms

- 🎯 **Audience Lab:** Explore target audiences and how designs communicate with them.
- 📣 **Ad Agency:** Learn about advertising and persuasive messaging.
- 🎨 **Color Control:** Discover how colors influence mood and communication.
- 🔤 **Type Foundry:** Explore typography, readability, and font choices.
- 💌 **Postcard Studio:** Apply design principles to create effective visual communication.

## 🎯 Learning Objectives

By completing this experience, students will practice:

- Identifying target audiences.
- Understanding persuasive advertising.
- Exploring color psychology.
- Selecting appropriate typography.
- Applying design principles.
- Solving problems through interactive challenges.

## 🕹️ How to Play

1. Open the Design Vault website.
2. Select **Enter the Vault**.
3. Complete the five design rooms.
4. Collect the digit earned in each room.
5. Enter the final code to unlock the vault.
6. Celebrate completing the mission!

## 💻 Technology

This project uses HTML, CSS, and JavaScript to create an interactive, browser-based learning experience.

## 🚀 Publishing with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click **Save**.

Make sure the main website file is named `index.html` for GitHub Pages to recognize it as the homepage.
